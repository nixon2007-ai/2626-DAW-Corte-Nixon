# Origen Amazónico – Página Web

## Semana 3

## Descripción
Este proyecto consiste en el desarrollo de una página web estática para un emprendimiento gastronómico llamado “Origen Amazónico”, el cual busca representar la cultura y los sabores tradicionales de la Amazonía ecuatoriana.

La página fue creada utilizando HTML5 y ejecutada con Live Server, incorporando etiquetas semánticas y contenido multimedia.

## Características principales
- Uso de **etiquetas semánticas** (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- **Menú de navegación interna**
- Secciones organizadas:
  - Inicio
  - Quiénes Somos
  - Productos y Servicios
  - Contacto
- Inclusión de **imágenes**
- Integración de:
  - 🎥 Video de YouTube
  - 🗺️ Mapa de Google Maps
- Enlaces a **redes sociales**
- Información adicional (promociones y horarios)

## 🛠️ Tecnologías utilizadas
- HTML5
- Live Server (Visual Studio Code)
