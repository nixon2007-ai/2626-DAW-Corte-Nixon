# Origen Amazónico

## Descripción del Proyecto

Origen Amazónico es un sitio web institucional desarrollado como parte del Proyecto Integrador de la Unidad 1 de la asignatura Desarrollo de Aplicaciones Web. El objetivo del proyecto es promocionar la gastronomía tradicional de la Amazonía ecuatoriana mediante una página web elaborada con HTML5 y etiquetas semánticas.

La página presenta información sobre el emprendimiento, sus productos y servicios, datos de contacto, promociones, imágenes y contenido multimedia relacionado con la cultura gastronómica amazónica.

## Características

* Estructura completa en HTML5.
* Uso de etiquetas semánticas:
 - Header
 - Nav
 - Main
 - Section
 - Article
 - Aside
 - Footer
* Menú de navegación interno.
* Sección de presentación del proyecto.
* Información institucional (Quiénes Somos).
* Catálogo de productos y servicios.
* Información de contacto.
* Enlaces a redes sociales.
* Imágenes relacionadas con el emprendimiento.
* Video de YouTube incrustado.
* Diseño inspirado en la naturaleza amazónica.

## Tecnologías Utilizadas

* HTML5
