# Sistema de Gestión y Venta de Celulares

## Descripción
Este proyecto corresponde a una página web básica desarrollada como parte de la asignatura Desarrollo de Aplicaciones Web (Paralelo "E").  

La página presenta una introducción a un sistema destinado a la gestión y venta de celulares tecnológicos.

## Características
- Página web estática construida con HTML5.
- Visualización de contenido introductorio.
- Inclusión de una imagen representativa (logo).
- Diseño simple ejecutado con **Live Server**.

## Tecnologías utilizadas
- HTML5
- Live Server (Visual Studio Code)

## Cómo ejecutar el proyecto
1. Descargar o clonar el repositorio.
2. Abrir la carpeta en **Visual Studio Code**.
3. Instalar la extensión **Live Server** (si no la tienes).
4. Hacer clic derecho en `index.html`.
5. Seleccionar **"Open with Live Server"**.

## Nota
Este proyecto es una práctica inicial para comprender la estructura básica de una página web que será desarrollada mas adelante.
